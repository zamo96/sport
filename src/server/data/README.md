# Generated server location data

`simplemaps-ru-names.json` maps every Russian row in `world-cities-json@1.0.1` to a Cyrillic display name. It was generated from the GeoNames RU country dump and `alternateNamesV2` Russian (`ru`) names, matched by coordinates and original aliases. The two GeoNames records without an explicit `ru` alternate name (`Рошаль` and `Звёздный`) were completed manually.

The map deliberately contains only SimpleMaps IDs and Russian display names. Stable place identity, population, region, and coordinates continue to come from SimpleMaps. Search indexes the Russian name plus both original SimpleMaps name fields, so Cyrillic and Latin queries produce the same place ID.
