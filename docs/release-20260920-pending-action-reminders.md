## Ограничения

- Напоминание `regular_slot_confirmation_waiting` (коммит `fe23275`) в этом
  релизе **отсутствует**: заработает только после следующего выката. Сейчас
  включены две кампании — `search_response_waiting` и `game_outcome_pending`.
- Ноль адресатов на dry-run означает только сегодняшнее состояние: долг появится,
  когда кто-то не ответит на отклик три часа или не отметит прошедшую игру.
  Фактическая доставка на устройства пока не наблюдалась.
- Тихие часы 22:00–09:00 по зоне игрока соблюдаются: включение прошло в 23:41 MSK,
  поэтому до утра напоминания не уйдут даже при появлении адресата.
- Корневой `/opt/tennis-search/.env.production` — отдельный старый файл, из него
  cron берёт только секрет; рубильник туда не добавлялся. Следующий деплой
  копирует `.env.production` из каталога релиза, так что значение переносится.

## Откат

Убрать строку `PENDING_ACTION_REMINDERS_ENABLED=true` (или поставить `false`) в
`.env.production` активного релиза и пересоздать только app теми же compose-файлами
с тем же образом. Эталон конфигурации — бэкап выше.
