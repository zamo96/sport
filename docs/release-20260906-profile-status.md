# Релиз: статус заполнения профиля в административной панели

## Поведение

Карточка игрока содержит отдельный блок «Статус профиля». Администратор выбирает «Черновик» или «Профиль заполнен» и сохраняет статус независимо от остальных полей, включая полностью пустой черновик. История модерации фиксирует автора и значения до/после; пользовательское событие завершения профиля не создаётся.
